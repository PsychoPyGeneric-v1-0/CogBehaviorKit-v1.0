Stimulus library

Everything that can be drawn on the screen lives in toolbox/stimuli.py. A stimulus is created from a small dictionary in your config.py; the "type" entry chooses the stimulus and every other entry sets one of its parameters. Anything you leave out takes the default value shown below.

"stimuli": {
    "target": {"type": "gabor", "size": 4, "sf": 3, "contrast": 0.2, "pos": [6, 0]},
    "fixation": {"type": "bullseye", "radius": 0.3}
}

The drawings below are a faithful preview made with the same defaults and formulas, shown on the usual mid-grey background (a browser drawing, so it will differ slightly from PsychoPy's own rendering). Units: sizes and positions are in degrees of visual angle by default; [0, 0] is the screen centre, negative x is left, positive y is up.

1. The default stimuli

Each stimulus drawn with no parameters changed.

2. Parameters of each stimulus

Parameters shared by most stimuli: pos (centre [x, y]), opacity (0 to 1), and colours, which can be names ("red"), hex codes ("#ff8800") or [r, g, b] values (0 to 255 in the default colour space). None as a fill colour means no fill. A parameter can be changed for one trial only with a trial variable named "<stimulus>.<parameter>", for example "target.contrast" computed in derive().

3. The Gabor in different settings

A Gabor is a sinusoidal grating (light and dark stripes) inside a soft window. Each row below changes one parameter and keeps the others at their default (size 4, sf 2, contrast 1, ori 0, phase 0, mask "gauss"). Every picture is on the same scale: the frame is 6 degrees wide.

4. Add your own stimulus

You do not need to edit the toolbox. Put a function in experiments/<name>/custom_stimuli.py; it is loaded automatically and then works with "type": "my_square".

from psychopy import visual
from toolbox.stimuli import register_stimulus

@register_stimulus("my_square")
def my_square(win, cs, rng, pos=(0, 0), size=1.0, color="white"):
    return visual.Rect(win, width=size, height=size, pos=pos, fillColor=color, colorSpace=cs)
