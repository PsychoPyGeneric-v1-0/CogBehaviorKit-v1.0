# Example output

Produced by `tools/make_example_output.py`, which runs the real toolbox against a **stand-in PsychoPy with a
random "participant"**. Column names, file layout and the `_README.txt` column guides are authentic; the **values
are not** (random RTs and accuracy, and `measured_*_ms` durations (whole milliseconds) come from the stand-in, not a real screen).

Each run creates three files with the same name: `.csv` (data), `_README.txt` (explains every column), `.json` (settings).
Open a `_README.txt` first.
